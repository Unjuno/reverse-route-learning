# Independent replication wanted

This project is intentionally a proof of concept rather than an optimized recovery system. The most useful next contribution is independent replication.

Please try one of the following:

1. reproduce the TinyStories-8M controlled suppression and reopening results;
2. rerun the capability-boundary benchmark on a different machine / software stack;
3. test the same procedure on another small causal Transformer;
4. improve candidate search for current false negatives such as `slide` and `meet`;
5. report a clean contradiction.

Use [replication-template.md](replication-template.md) when reporting results. Negative replications are useful and should not be filtered out.
