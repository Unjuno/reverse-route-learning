# TinyStories results

Selected raw result files from the public proof of concept are stored here.

- `tb98_fresh_reconvergence_scan_summary.json` — early fresh post-only candidate scan.
- `tb99_blind_set_repair.json` — early blind candidate-set reopening demonstration.
- `tb100_strength_sweep_summary.json` — suppression-strength sweep.
- `tb102_basefree_kl_stopping.json` — KL-bounded base-free stopping.
- `tb107_tb111_summary.json` — divergent-route normality and deep-eroded controls.
- `tb112_tb113_summary.json` — historical-identifiability negative results.
- `tb114_operational_boundary.json` — **current fixed-protocol capability boundary; use this as the primary v0.1 benchmark.**

The earlier TB98/TB99 files use exploratory settings and should not be compared numerically to TB114 as if they were the same protocol. The base checkpoint is used only for controlled construction and oracle evaluation where explicitly stated; post-only candidate ranking and repair target selection do not use it.
