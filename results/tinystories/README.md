# TinyStories results

Selected raw result files from the public proof-of-concept are stored here.

- `tb98_fresh_reconvergence_scan_summary.json` — fresh post-only candidate scan.
- `tb99_blind_set_repair.json` — blind candidate-set reopening.
- `tb100_strength_sweep.json` — suppression-strength sweep.
- `tb102_basefree_kl_stopping.json` — KL-bounded base-free stopping.
- `tb107_tb111_summary.json` — divergent-route normality and deep-eroded controls.
- `tb112_tb113_summary.json` — historical-identifiability negative results.
- `tb114_operational_boundary.json` — fixed-protocol current capability boundary.

The base checkpoint is used only for controlled construction and oracle evaluation where explicitly stated; post-only candidate ranking and repair target selection do not use it.
